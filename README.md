Study Habits and Student Well-being

Purpose

This fictional class project explores how daily study habits relate to student well-being. It aims to
practice organizing a research project using version control, from planning through data collection
notes.

Files
- project_plan.docx – outlines the project goals, timeline, and team responsibilities
- survey_draft.docx – contains the draft questions for the fictional student survey
- data_dictionary.xlsx – describes the (fictional) variables and response codes used in the survey

Team rules
1. Name files using lowercase words separated by underscores (example: survey_draft_v2.docx) and
include a version number when revising.
2. Announce any major change to shared files in the team chat before committing, with a short note
on what was updated.

Privacy reminder
No personal records or identifiable participant data may be uploaded to this repository. All content
must remain fictional or fully non-sensitive.

Next step
